# Training Estimator V4 - Model-size-aware Correction Report

## Goal

Improve TrainingMemoryEstimator V3 by making SGD backward temporary correction model-size-aware.

## Motivation

TrainingMemoryEstimator V3 used optimizer-specific correction only.

It improved gpt2 SGD but damaged distilgpt2 SGD.

This showed that optimizer-specific correction alone was not enough.

## V4 Change

TrainingMemoryEstimator V4 uses optimizer-specific and model-size-aware backward temporary factors.

| case | backward_temp_factor |
|---|---:|
| AdamW | 0.65 |
| Adam | 0.65 |
| SGD for small/medium models below 100M parameters | 0.65 |
| SGD for large models above/equal 100M parameters | 0.35 |
| SGD with momentum | 0.45 |
| default | 0.50 |

## Parameter Threshold

V4 uses 100M parameters as the large-model threshold.

distilgpt2 has about 82M parameters, so its SGD factor remains 0.65.

gpt2 has about 124M parameters, so its SGD factor becomes 0.35.

## Main Interpretation

V4 tests whether model-size-aware SGD correction can keep the gpt2 SGD improvement from V3 while avoiding the distilgpt2 SGD damage.

If V4 matches V2 on distilgpt2 SGD and matches V3 on gpt2 SGD, it is a better estimator design than both V2 and V3.

## Next Step

Use V4 as the candidate final training estimator if it improves global metrics without damaging any major subgroup.
